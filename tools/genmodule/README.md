# genmodule

`genmodule` creates module sources, SDK headers and library definitions from
the source-owned module configuration.

## Reproducible dates

Set `SOURCE_DATE_EPOCH` to an explicitly selected nonnegative decimal Unix
timestamp to make the generated banner year and default module date use UTC.
An explicit `date` in the module configuration remains unchanged. An unset
variable preserves the historical UTC banner year and local current date.

Empty, signed, whitespace-containing, malformed or overflowing values are
errors before generation opens any output file. The timestamp must fit the
host's `time_t` and the four-digit banner calendar (through 9999-12-31 UTC).
The generator does not select a source revision or an epoch for the caller.

Run the actual-generator regression from the repository root:

```sh
python3 scripts/ci/test_genmodule_epoch.py
```

The test builds the host generator in an automatically cleaned temporary
directory and checks complete generated bytes, default and explicit module
dates, time-zone independence and invalid-input rejection. It is a generator
test, not a complete SDK reproducibility or release qualification.
